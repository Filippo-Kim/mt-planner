# AI 코딩 도구 사용 기록

## 사용 도구
Claude (Anthropic)

## 활용 방식

### 1. 기획 단계
서비스 아이디어를 구체화하고, 페이지 구성·AI 기능 입출력 명세·실패 처리 기준을 표로 정리했다.

### 2. 코드 작성
HTML/CSS/JS 및 Python 서버리스 함수의 초안을 생성하고, 요구사항에 맞게 수정했다.

### 3. 디버깅 (가장 비중이 컸던 부분)

**사례 1: Vercel Python 런타임 인터페이스 오류**
- 증상: `RuntimeError: Could not determine the application interface`
- 진단: 최신 런타임이 WSGI 인터페이스를 요구
- 해결: `BaseHTTPRequestHandler` → `app(environ, start_response)` 전환

**사례 2: Gemini 모델 404**
- 증상: "AI 서버에 일시적인 문제가 있어요" (사용자 메시지로만 표시)
- 진단: 에러 원문을 임시 노출하도록 코드 수정 → 모델 폐기 안내 확인
- 해결: 모델명 갱신 후 디버그 코드 원복

**사례 3: 함수 실행 시간 초과**
- 증상: 응답 지연 메시지 반복
- 진단: Vercel 함수 기본 제한 시간 초과 추정
- 해결: `maxDuration` 60초 설정 + 프롬프트에 출력 길이 제한 추가

## 배운 점
에러 메시지를 사용자 친화적으로 감싸는 것은 운영상 옳지만, 디버깅 시점에는 원문 확인이 필요하다. 임시 디버그 코드를 넣고 원인 확인 후 즉시 원복하는 방식이 효과적이었다.
